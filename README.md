# CryptoLedger Pro v5.0

Accounting-ready crypto wallet ledger — FIFO gains, 
transaction classification, and Excel output.

## Features
- Multi-chain: Ethereum, Polygon, Arbitrum, BSC, Base, 
  Optimism, Avalanche, Fantom, Bitcoin, Solana
- FIFO capital gains with short/long-term split
- Auto transaction classification (30+ types)
- Historical USD prices via DefiLlama (no API key needed)
- 7-sheet Excel output with clickable tx hash proof links
- Data quality report for audit trail

## Requirements
Python 3.10+  
pip install requests openpyxl

## Usage
python cli.py
